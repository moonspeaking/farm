# PWA (TypeScript + PixiJS)

Порт первой фермы. Графика, тексты из оригинала, код написан заново.

https://moonspeaking.github.io/farm

Вторая часть портируется рядом, в `~/PycharmProjects/MagicFarm2Port`. Там ресурсы упакованы
в `main.pak`, а анимации лежат в 3D-формате `.a3d`. В первой части всё проще: обычные картинки
PopCap (`X.jpg` — цвет, `X_.png` — альфа в яркости), а правила лежат в XML без архива.

Что выяснено по дизассемблеру exe (формулы, адреса функций, что осталось допущением) — в
[`docs/EXE_REVERSE_NOTES.md`](docs/EXE_REVERSE_NOTES.md).

## Ресурсы

```bash
GAME="$HOME/Library/Application Support/CrossOver/Bottles/Farm/drive_c/Program Files/Game0"
python3 tools/export_mf1.py "$GAME" web     # нужен Pillow
```

Скрипт кладёт картинки в `web/public/img/*.webp` (с альфой), звуки — в `web/public/audio`, правила и русские тексты —
в `web/public/data/rules.json`. Шрифты, курсоры и частицы экспортируют `tools/export_fonts.py`, `export_cursors.py`,
`export_particles.py`. Источники в игре:
- `xml/properties_ru.xml` — растения, продукты, вредители, Робин, умения, стартовые значения (`common`), туториал, раскладка экранов;
- `xml/locations/location_N.xml` — длина дня, колодец, бочки и ящики по уровням, набор семян, грядки, волны вредителей;
- `xml/locations/location_N_quests.xml` — квесты четырёх локаций;
- `xml/locations/items.xml` — цены грядки, воды и колодца;
- `xml/ru/ru.xml` — все надписи (в cp1251 без объявления кодировки).

## Запуск и установка (PWA)

```bash
cd web
npm install
npm run dev            # http://localhost:5173, ?speed=10 ускоряет игровые таймеры
npm run build          # проверка типов и сборка в web/dist (с sw.js для офлайна)
```

- Публикация: GitHub Pages из ветки `gh-pages`; при пуше в `main` workflow `.github/workflows/pages.yml` собирает игру и кладёт
  сборку в эту ветку одним коммитом (без артефактов Actions и их квоты). Пути в сборке относительные.
- Установка на телефон: открыть страницу в Chrome → меню → «Установить приложение» / «Добавить на главный экран».
  Запускается на весь экран (`display: fullscreen`) в альбомной ориентации, после первой загрузки работает без сети.
  В браузере клавиша F включает и выключает полный экран.
- Обновление: новая версия ищется только при запуске. Если она пришла, пока игрок в главном меню, страница
  перезагружается сама; если игра уже идёт — ничего не спрашивается, новая версия включится при следующем запуске.
- Экран 800×600, как в оригинале, вписывается в окно с полями; цвета выводятся в Display P3 (как оригинал под CrossOver на Mac).

## Хранение

Всё лежит в `localStorage` браузера на устройстве, обращения к нему собраны в одном модуле `web/src/storage.ts` (ключи, чтение и запись JSON, запасное хранение в памяти, если браузер не даёт писать). При запуске запрашивается постоянное хранилище, но оно защищает только от автоматической очистки при нехватке места. Установленное PWA делит хранилище с сайтом: очистка кэша и истории прогресс не трогает, а «Файлы cookie и данные сайтов» стирает его.
- `iris-farm-profiles` — игроки и текущий игрок;
- `iris-farm-save-v3:<id>` — сохранение игрока (все четыре локации, квесты, умения, флаги подсказок);
- `iris-farm-options` — опции (общие), `iris-farm-scores` — рекорды (общие).

Картинки делятся на общие (`core_images`, грузятся при запуске) и по локациям (`location_images`: вредители, фоны,
ящики, портреты). Картинки локации подгружаются при первом входе в неё (а локация, где остановился игрок, догружается в фоне прямо в главном меню — «Кампания» открывает игру без экрана загрузки), картинки других локаций выгружаются: на запуске
≈40 МБ распакованных картинок вместо ≈85 МБ. Разбиение считает `tools/export_mf1.py` (`split_images`).

## Экраны

Кнопки только из оригинала: круглые `buttons/back`, кнопки магазина `shop_button_small/medium` на объектах,
текстовые кнопки без подложки в цветах `button_styles` (`normal` — «Да», «Нет», «OK», «Назад»;
`shop` — «Один», «Все»; `menu` — пункты главного меню). Шрифты — растровые шрифты оригинала.

**Экран загрузки** (`BugsLoadingScreen`): ромашка зацветает по проценту, случайный вредитель ползёт справа налево
(x = (1 − процент) · 800), надпись «Идет загрузка...» едет за ним. Процент растёт ровно, не быстрее 1/3 в секунду
(экран держится минимум 3 с); каждый клик по экрану сокращает ожидание на 1 с.

**Игроки** (`select_user`, `new_user`): как в оригинале, можно завести несколько учётных записей. При первом запуске
игра спрашивает имя («Введите ваше имя.»), вверху главного меню — «Приветствую, %name%, если это не Вы, нажмите сюда»,
по нажатию — список игроков («Создать», «Удалить», OK). У каждого игрока своё сохранение и свои подсказки, рекорды и
опции общие; в рекорды пишется имя игрока. Сохранение, сделанное до появления игроков, достаётся первому созданному.

**Главное меню** (`main_menu`): «Кампания», «Опции», «Об игре», «Результаты». «Кампания» сразу продолжает игру,
если у игрока есть сохранение; без него начинается новая игра со вступительного комикса (`first_comics`) и попадает
в город к слуге. Начать заново можно, удалив игрока и создав нового (в оригинале есть выбор «Новая игра», здесь он убран). Вместо «Выйти» — «Об игре» (браузер и PWA не могут закрыть себя сами): четыре страницы о том,
как играть, о вредителях и Робине, об управлении и о порте.

**Опции**: громкость музыки и звуков, полный экран, «Специальные Курсоры» (курсоры оригинала: стрелка, покупка,
продажа, разговор, полив, сбор, меч; у кнопок — стрелка), «Предупреждения в игре» (подсказки обучения), а также
добавленные в порте «Блестки» (частицы у счётчиков) и «Итоги дня».

**Меню игры** (Esc или «Меню»): «Вернуться», «Опции», «Выйти» в главное меню. Пробел — пауза. Пока открыто меню,
пауза или подсказка днём, игровые таймеры стоят.

**Карта мира** (`global_map`): города и фермы четырёх локаций, открытые квестами подсвечиваются при наведении
(курсор — рука). У городов с заданиями — искры (`level-available-quests`).

**Город** (`town_screen`): персонажи стоят по позициям `quest_holders`, над тем, у кого есть задание, висит значок;
персонаж появляется, когда у него есть задание. Сверху — «На Карту» и «На Ферму».

**Разговоры** (`quest_dialog`): свиток, портрет говорящего (`talkers/*`), имя, реплика, стрелки «назад/дальше»,
варианты ответа; недоступные ответы скрыты.

**Квесты** четырёх локаций: тексты из `ru.xml` сопоставляются по порядку (`phrase_N` ↔ N-я реплика, `answer_N` ↔ N-й ответ).
Движок (`web/src/quests.ts`) выполняет все условия (`have_mark`, `have_items`, `quest_status`, `day_delay`,
`have_empty_ridge`) и все действия словаря exe (`set_mark`, `add_items`, `enable_helper`, `enable_town`/`farm`,
`enable_bug_item`, `remove_all_vegetations`, `clear_bouquets` и др.). Сюжет проходится до конца (метка `win`,
подсказка `game_fin`), после — свободный режим.

**Букеты**: экран цветочного магазина — корзина с цветами, перетаскивание цветов в 4 заказа, оплата за готовый букет,
продажа по одному («Один» / «Все»).

**Умения**: опыт и уровни из `skills.xml`, окно «Поднять уровень». Значение умения = 1 + сумма прибавок за уровни
(с пределом `skill_limits`), для `buy_goods`, `new_product`, `new_product_specific` — 1 − сумма. Особые умения по видам
растений и вредителей растут от числа собранных плодов и убитых вредителей.

## Игра на ферме

Слева панель Айрис (опыт, склад, вода, деньги, день, «Меню»), сверху справа часы дня с погодой.

**Подготовка к дню.** Магазин работает прямо на объектах фермы (`shop_control/click_obj_buttons`): посадить и продать
растение, купить грядку, бочку, ящик, колодец, купить воду, продать плоды (экран букетов), «Начать День» с
предупреждениями оригинала («Мало воды. Все равно начать день?»). Новое открывается по дням метками
`set_mark_by_day`: бочка с 5 дня, ящик с 6, другие растения с 7, грядки с 10, колодец с 12 (на ферме 1).

**День** длится `time` из `location_N.xml` (на ферме 1 — 40 с). Погода выбирается раз в день: до 5-го дня обычная,
дальше поровну обычная, солнце, дождь (множители жажды, роста плодов и прихода вредителей).
- Растение живёт без полива `T0 = rand(hunger_min…hunger_max)` с учётом погоды и умения; хочет пить при `T < T0/2`
  (капли над ним убывают), гибнет при `T ≤ 0`, к концу краснеет. Полив стоит 1 литр.
- Плоды растут за `min…max_product_delay` (с погодой и умениями) в узлах `nodes`, продукт выбирается по `probability`;
  собираются на склад, пока на нём есть место. Растение переходит на следующую стадию после `upgrade` поливов.
- Бонусы: «Быстрый / Очень быстрый / Моментальный» сбор и полив (опыт ×2/×3/×4) и «Экономный Полив» (×2), серии «xN».
- Бочки и ящики — отдельные объекты, их вместимость складывается (ферма 1: 8 → 18 → 30 л, 15 → 35 → 60 плодов).
- Колодец: ведро на `water_capacity` литров, после использования — пауза `delay` и наполнение `fill_time`;
  картинка ведра — по `skin_ru.xml → well_ctrl`.

**Вредители** (`bugs`, `bug_arriver`): волны идут по кругу, а не по одной на день, и счёт волн переживает смену дней
(сбрасывается только при загрузке). У группы все вредители выходят сразу, затем пауза `delay` группы; после всех групп —
пауза `delay` волны, которая идёт, только пока на поле нет вредителей. Паузы умножаются на погоду `bug_arrive` (в дождь
0,8 — чаще). Вредители появляются у краёв фермы (`arrive_positions`). Каждый выбирает случайное растение и идёт к нему по
сетке клеток 25 × 15 (волна Ли, обход препятствий и друг друга), затем непрерывно ест: `attack · dt` жизни растения.
Нажатие бьёт мечом: урон = оружие × (1 + attack) × (1 + attack_specific вида). Анимации `move / eat / hit / stand /
reincorn` в 5 направлениях, влево — зеркально. Предметы квестов выпадают, пока квест разрешил это (`enable_bug_item`).

**Робин** (`common/helper`) появляется после квеста слуги. Каждый раз, когда дела нет, он бросает вероятности
`start_skill_prob + per_level_skill_prob × уровень` для сбора, полива и атаки и берёт ближайшую цель первого выпавшего
дела; ничего не выпало — гуляет к случайной клетке. Ходит по той же сетке, что вредители, и занимает клетки. Удар —
`attack · (1 + helper_attack)` раз в `attack_period`; умения `*_speed` ускоряют полёт к цели своего дела. Поливает
бесплатно, собирает все спелые плоды растения. Над ним иконка текущего дела.

**Подсказки обучения** (тексты `ru.xml → tutorial`, раскладка `properties_ru.xml → tutorial`): окна с затемнением и
«окном» под целью показываются по одному и один раз и днём ставят игру на паузу до «Закрыть»; пузыри магазина
(«Посадить», «Продать», «Купить воду») висят, пока игрок не сделал действие; простые пузыри идут вместе с игрой и живут
10 с. Напоминания экранов («Нажмите эту кнопку для начала дня», «…на ферму», «…в город») повторяются каждые 10 с,
пока нет другой подсказки. Условия показа перенесены по exe.

**Частицы** `.psi` (`data/particles`) разобраны по exe: звёздочки вылетают из счётчиков панели, искры над полоской
опыта при свободных очках умений и у городов с заданиями на карте.

## Отличия от оригинала

Всё, что раньше было допущением, разобрано по exe (подробнее — в заметках). Осознанные отличия:
- на ферме 3 ведро стоит у колодца: в оригинале его картинка берётся из одной записи skin для всех ферм (240; 440),
  а колодец там сдвинут;
- экран загрузки держится минимум 3 с и ускоряется кликом (в оригинале — минимум 5 с);
- режим наложения частиц — аддитивный (в коде не определён);
- в главном меню «Об игре» вместо «Выйти», в опциях добавлены «Блестки» и «Итоги дня».
